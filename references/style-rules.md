# 文体语域规则与中式英语修正清单

## 1. 五种学术文体的语域差异

| 文体 | 语域特征 | 人称与语态 | 禁忌 |
|-|-|-|-|
| 期刊论文 | 客观、克制、结论由证据限定 | 第一人称复数或被动均可，避免随意切换；时态按惯例（引言一般过去/现在完成；方法过去时；结果过去时；结论现在时） | 宣传语（novel、first、breakthrough 无据使用时）；感叹号；绝对化（prove 级结论对应因果证据；correlate 证据只能用 indicate/suggest） |
| 学位论文 | 较期刊论文略正式，可保留章节性表述 | 第三人称或无人称；方法可适度详细 | 口语化连接（其实、个人觉得）；跨章术语漂移 |
| 基金申请书 | 论证驱动，允许必要评价性表述但每个评价须有依据 | 本项目/申请人/项目组；面向评审的逻辑推进（背景—现状—问题—方案—影响） | 空洞口号（填补空白、国际领先无支撑时）；人称混用（我/我们/本团队混排） |
| 审稿回复 | 礼貌、逐条、不防御；感谢—说明—修改位置三段式 | 直接回应（"感谢审稿人指出…，我们已修改…"） | 指责审稿人；未做修改时含糊其辞；改变事实立场而非澄清 |
| 英文摘要 | 信息密度高、自洽（摘要独立于正文可读） | 主动语态优先但不强制；过去时描述方法与结果，现在时陈述结论 | 摘要内引用编号与图表指向（除非期刊允许）；材料中无据的结论性表述 |

**文体判定**：任务说明未指明时，依据任务材料类型推断（投出稿→期刊论文；评审场景→审稿回复；项目申报→基金申请书），并在 `uncertainty` 中记录推断依据。判不出时按期刊论文处理。

## 2. 学术语气的通用红线

1. 删除口语化连接词：其实、说白了、一般来说、obviously、of course、needless to say。
2. 抑制宣传化与绝对化："首次""独创""革命性""完美""completely eliminate""undoubtedly"无材料支撑时删除或降格为有依据的表述（`REGISTER`）。
3. 人称统一：一篇内不得 I/we/我们/本研究混用；中文以无人称（本文/本研究）优先。
4. 结论强度与证据匹配：相关结果只写"相关"，随机对照且达标才可用"证明/导致"级。
5. 数量限定词保留：约、近、超、约（approximately、about、over）不得增删。

## 3. 中式英语与直译腔修正清单（CHINGLISH）

| 病型 | 直译腔示例 | 推荐表述 |
|-|-|-|
| 动词名词化冗余 | make a study of / perform an analysis on | study / analyse |
| 介词冗余 | research on → study 后接直接宾语；remove away | study X directly / remove |
| 主语空泛 | With the rapid development of… | 删除套话或改写为具体进展 |
| 逻辑连接词滥用 | because…so…；Although… but… | 只用其一（英文绝对禁止双连接） |
| 定语堆叠 | the … of the … of the … | 拆分或改用 hyphenation/修饰语前置 |
| there be 堆积 | There are many researchers who think that… | Researchers argue that… |
| very/十分等空程度副词 | very important | important / crucial（有材料依据时） |
| 时间状语位置错位 | In this paper, we… 位于句中 | 置于句首或句末，一处即可 |
| 中译英重心错位 | 以物作主语的直译被动句 | 按英文信息重心重排主语（原文无施事时用被动，有施事时优先主动） |
| 单复数与冠词 | advancements were made in an field | 依名词可数性与发音规则校正 |

## 4. 长句切分规则（SYNTAX）

- 60 词（英文）或 80 字（中文）以上且含两层以上嵌套从句的句子优先切分；
- 切分点优先选择在并列谓语、时间/条件从句边界；切分不得改变条件与主句的依附关系；
- 切分后每句主语明确；原文的因果、条件、让步关系必须保留原连接词；
- 切分造成的句序变化必须逐句记入 edit_log。

## 5. 标点与中英混排

- 英文文本：半角标点+空格规范；不得残留全角标点；
- 中文文本：全角标点；英文缩写、公式、数字之间的连接用半角；
- 期刊名称、基因名、化学式的大小写按领域惯例（基因斜体、元素符号首字母大写等），无把握时在 `uncertainty` 标注。
