# 学术润色自查评分表（可复用）

本表供作者或第三方在润色交付前逐项核验，也适用于评估任何润色结果（人工或工具）。每项 0–2 分：0 = 未做到，1 = 部分做到，2 = 完全做到。总分 40 分；**任何一项"守恒"项为 0 分时，整稿不得交付**。

## 1. 改得对（10 分）

| # | 检查项 | 0–2 |
|-|-|-|
| 1.1 | 主谓一致、时态语态、单复数、冠词介词等硬错误已修正 | |
| 1.2 | 悬垂修饰、指代不明、长句嵌套已处理，切分未改变逻辑关系 | |
| 1.3 | 标点与中英全半角混用已修正 | |
| 1.4 | 搭配与用词符合学科惯例，非仅换一种说法掩盖错误 | |
| 1.5 | 中式英语／直译腔已按清单修正（`style-rules.md` §3） | |

## 2. 说得像（10 分）

| # | 检查项 | 0–2 |
|-|-|-|
| 2.1 | 全稿符合目标文体语域（期刊／学位论文／基金／审稿回复／摘要） | |
| 2.2 | 术语全篇统一，无跨章节漂移 | |
| 2.3 | 缩写首次出现形式正确，其后用法统一 | |
| 2.4 | 人称与语态全篇一致，无口语化、宣传化、绝对化表述 | |
| 2.5 | 文本仍像同行撰写的学术文本，无翻译腔或机器腔 | |

## 3. 没改坏（10 分，守恒项）

| # | 检查项 | 0–2 |
|-|-|-|
| 3.1 | 数字、单位、误差范围、样本量零改动（脚本核验通过） | |
| 3.2 | 引用编号、`\cite` 键、图表指向、`\ref` 标签零改动 | |
| 3.3 | 限定强度未被加强或削弱（脚本核验＋人工复核带标注项） | |
| 3.4 | 因果／相关、否定范围、条件句、量词保持原样 | |
| 3.5 | 未新增材料之外的事实、引文或比较 | |

## 4. 讲得清（10 分）

| # | 检查项 | 0–2 |
|-|-|-|
| 4.1 | 每处修改有原文—改文对照 | |
| 4.2 | 每处修改有类型标签（GRAMMAR/TERM/REGISTER/…） | |
| 4.3 | 每处修改有第三方可判断的修改理由 | |
| 4.4 | 守恒校验报告随稿交付，硬违规为零 | |
| 4.5 | 材料缺口、冲突、需人工确认项已逐条标注 | |

## 使用建议

- 润色执行者自评一遍，再由未参与编辑的第三方（或审校通道）复评一遍；两次评分差异超过 4 分的项目逐条讨论；
- 3.1–3.5 任一得 0 分即整稿退回，不适用总分豁免；
- 本表可直接打印或并入稿件修改记录，与 `edit_log.md`、`verification_report.json` 一并归档。
