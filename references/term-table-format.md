# 术语表格式规范

术语表用于驱动全篇一致性回扫（阶段 3），并为 `check_polish.py --terms` 提供校验依据。格式为 UTF-8 编码的 TSV（制表符分隔），无表头，每行一个术语。

## 1. 字段定义

```
规范写法<TAB>可接受变体1,可接受变体2<TAB>禁用写法1,禁用写法2<TAB>首次出现要求<TAB>备注
```

| 列 | 必填 | 说明 |
|-|-|-|
| 规范写法 | 是 | 全篇统一使用的写法（中文、英文或缩写） |
| 可接受变体 | 否 | 允许出现但不推荐的写法；脚本发现时记 `TERM` 提示 |
| 禁用写法 | 否 | 禁止出现的写法（错误译法、旧名、易混淆缩写）；脚本发现时记硬违规 |
| 首次出现要求 | 否 | `FULL_FIRST`：首次出现须写全称+缩写；`ABBR_OK`：可直接用缩写；`NONE`：无要求 |
| 备注 | 否 | 学科惯例、大小写/连字符规则、易混词提示 |

## 2. 示例

```tsv
深度学习	deep learning	深层学习,深度学習	FULL_FIRST	英文首次出现：deep learning (DL)；此后统一 DL
强化学习	reinforcement learning, RL	加强学习	FULL_FIRST	缩写 RL 仅限摘要与正文，图表标题用全称
CRISPR-Cas9	CRISPR/Cas9	crispr-cas9,CRISPR-cas9	ABBR_OK	注意 Cas9 大小写
```

## 3. 首次出现规则

1. 英文术语在中文稿件中的首次出现：**中文全称（英文全称，缩写）**；此后统一用缩写或中文规范写法，不得混用。
2. 英文稿件中的缩写首次出现：**Full Name (ABBR)**；摘要与正文分别计首次（多数期刊惯例），全文仅定义一次。
3. 同一概念不得在不同章节换用同义词（如方法章用 "encoder"，结果章不得改为 "coding network" 指同一模块）。
4. 大小写与连字符全篇统一（如 "deep learning" 不作定语时不加连字符，"deep-learning model" 作定语时可加）。

## 4. 冲突处理

术语表内部冲突（同一概念两行规范写法、缩写与另一术语全称冲突）时：

1. 以原文使用频次更高者为规范；
2. 冲突项写入 `result.json` 的 `uncertainty`，说明选择了哪一写法及依据；
3. 不擅自合并或删除冲突条目。
