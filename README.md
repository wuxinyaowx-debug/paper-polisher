# paper-polisher

学术语言润色 Agent Skill：以**最小编辑**与**语义守恒**为核心，对中/英文学术文本执行分句级润色，交付"润色后完整文本＋逐句修改说明＋守恒校验报告"三份产物，每一处修改均可被第三方复核。

## 解决什么问题

基础 Agent 润色学术文本时的典型失败模式：整段重写导致限定词消失（"提示"变"证明"）、术语在引言与方法之间漂移、数字与引用编号被顺手改动、修改无记录无法复核。本 Skill 针对"语义保持与最小编辑"这一具体问题，给出可真实运行、独立验证的最小方案：

- **改得对**：语法、句法、搭配、标点硬错误真正修正，非换一种说法掩盖；
- **说得像**：五种学术文体（期刊论文／学位论文／基金申请书／审稿回复／英文摘要）语域规则，术语表驱动全篇一致性回扫；
- **没改坏**：限定强度五级词表守恒、数字/单位/引用编号/图表指向零改动，由确定性脚本核验；
- **讲得清**：逐句"原文—改文—修改类型—理由—核验"记录，附可复用四维自查评分表。

## 目录结构

```
├── SKILL.md                        # Skill 本体：触发条件、五阶段流程、输出契约、异常处理
├── references/
│   ├── style-rules.md              # 五种文体语域规则、中式英语修正清单、长句切分规则
│   ├── hedge-scale.md              # 中英限定强度五级词表（守恒校验依据）
│   ├── term-table-format.md        # 术语表 TSV 格式规范与首次出现规则
│   └── self-assessment.md          # 可复用自查评分表（四维 20 项）
├── scripts/
│   └── check_polish.py             # 守恒校验脚本（Python ≥ 3.8，仅标准库）
└── examples/                       # 最小调用示例（英文/中文各一组，标明为示意）
```

## 快速开始

1. 将本目录作为 Skill 加载到支持 SKILL.md 约定的 Agent（触发场景：学术文本润色、术语统一、中式英语修正、中译英学术改写）。
2. Agent 按 `SKILL.md` 五阶段流程执行：文体判定 → 术语表建立 → 分句最小编辑 → 守恒校验 → 交付标注。
3. 守恒校验脚本单独也可用于任何润色结果的事后核验：

```bash
python scripts/check_polish.py --orig 原文.txt --new 润色稿.txt \
    [--terms 术语表.tsv] --out 报告.json
```

- 退出码 0：通过或仅有软警告；退出码 1：存在硬违规（数字/引用/图表指向被改动、限定强度被加强、使用术语表禁用写法），应返修后重新校验；
- 支持 LaTeX 输入：`\cite{}` 键名与 `\ref{}`/`\eqref{}` 标签纳入多重集守恒比对。

## 输出产物

| 产物 | 说明 |
|-|-|
| 润色后完整文本 | 保持原文档结构，可继续编辑 |
| `edit_log.md` | 逐句修改说明：原文—改文—类型标签—理由—核验结论 |
| `verification_report.json` | 脚本守恒校验报告（数字/引用/图表/限定强度/句数/术语） |
| `result.json` | 结构化结果：`case_id`、`status`、`sources`、`uncertainty`、`changes` 及任务方声明的全部契约字段 |

## 适用范围与限制

- 适用：中/英文期刊论文、学位论文、基金申请书、审稿回复、英文摘要的润色与术语治理；
- 不适用：扩写、缩写、内容生成、非学术文体；
- 已知限制：术语"可接受变体"检测不区分首次出现语境（保守方向误报，需人工按术语表规范销记）；事实正确性无法自动核验，需人工确认项会在 `uncertainty` 中明确标注。
